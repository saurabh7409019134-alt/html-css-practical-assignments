# Box model explanation

An element's **content** holds text or child content. **Padding** adds space between that content and the border. The **border** surrounds the content and padding. **Margin** adds outside space between the element and its neighbors. With `box-sizing: border-box`, declared width includes content, padding, and border; margins remain outside that width.
