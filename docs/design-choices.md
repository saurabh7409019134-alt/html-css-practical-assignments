# Design choices

The project uses a calm navy, blue, mint, and warm peach palette with a system-font stack for broad compatibility. Rounded cards and consistent spacing make examples cohesive, while each page uses a small, visible task label to keep the assignment easy to review. Layout exercises focus on the named concept: Flexbox pages show alignment and wrapping; Grid pages show responsive tracks and named areas; responsive pages use explicit breakpoints.

Text that could imply personal history, college identity, contact information, or achievements is marked as an editable placeholder or sample. Task 43 is an original educational landing page because no reference design was supplied. Task 45 uses a Google Fonts import as an enhancement with a system-font fallback; it still renders if external fonts are unavailable.
